# User Flows

## Discover An Opportunity

1. User opens the opportunity listing.
2. User enters a search term or selects filters.
3. System updates the list with matching opportunities.
4. User opens an opportunity detail page.
5. User follows the source URL or saves the opportunity.

## Save And Track An Opportunity

1. User opens an opportunity.
2. User clicks save.
3. System adds the opportunity to the user's saved list.
4. User chooses a tracking status.
5. User optionally adds notes.
6. System shows the opportunity in saved and deadline views.

## Admin Adds Opportunity

1. Admin opens the opportunity management screen.
2. Admin creates a new listing.
3. Admin enters required fields and source URL.
4. System validates deadline, URL, and required fields.
5. Admin saves the listing as draft or published.
6. Published listing appears in discovery.

## Review Expiring Opportunities

1. User opens saved opportunities or deadline view.
2. System groups opportunities by due date.
3. User reviews upcoming deadlines.
4. User updates status or archives irrelevant opportunities.
