# Opportunity Radar Speckit

This folder contains the working specification kit for Opportunity Radar. It is meant to be a living planning space before implementation starts.

## Contents

- [product-brief.md](product-brief.md): product intent, users, goals, and assumptions.
- [requirements.md](requirements.md): functional and non-functional requirements.
- [user-flows.md](user-flows.md): key workflows and user journeys.
- [data-model.md](data-model.md): initial domain entities and relationships.
- [api-sketch.md](api-sketch.md): proposed API surface.
- [milestones.md](milestones.md): staged delivery plan.
- [open-questions.md](open-questions.md): decisions still needing owner input.

## How To Use

1. Review `product-brief.md` and update the assumptions.
2. Resolve the highest-impact items in `open-questions.md`.
3. Convert accepted requirements into issues or implementation tasks.
4. Keep this folder updated as product decisions change.
